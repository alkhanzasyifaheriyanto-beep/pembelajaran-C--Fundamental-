## 📘 Tentang Repository  
Repository ini dibuat sebagai tempat pembelajaran **fundamental C++**.  
Berisi materi dasar, contoh kode, dan latihan untuk memahami konsep penting dalam pemrograman C++.

---

## 🎯 Tujuan Pembelajaran
- Menguasai dasar sintaks C++  
- Memahami variabel, tipe data, operator  
- Menggunakan control flow  
- Membuat fungsi dan memahaminya  
- Bekerja dengan array, pointer, dan reference  
- Memahami dasar OOP (class, object, constructor)
